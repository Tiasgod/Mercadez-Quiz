# Quiz Mercadez — Desafio do Precinho

Projeto estático em HTML, CSS e JavaScript. Abra index.html no navegador ou use Live Server no VS Code. Para publicar na Vercel, importe um repositório contendo estes arquivos na raiz, selecione Other e deixe Build Command vazio. Não é necessário instalar dependências.

Cada pergunta dura 30 segundos. Se o tempo terminar, a alternativa selecionada é registrada (ou a questão fica sem resposta) e o quiz avança. Cada acerto vale 20 pontos. As imagens em assets são provenientes do pacote drawable fornecido. A marca textual no cabeçalho é uma composição provisória em CSS.
